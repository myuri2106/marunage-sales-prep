# 商談準備シート自動作成ツール（丸投げコネクト営業用）

商談相手の **ホームページURLを入れるだけ** で、商談前に必要な情報を自動で集めて
`商談準備シート.md` にまとめるツールです。VSCode からワンクリックで実行できます。

## 自動で集めるもの

| 内容 | 取得元 |
|---|---|
| 会社名・代表者・設立・資本金・従業員数・所在地・電話・事業内容など | 会社概要ページの表 |
| 事業内容・サービス・実績 | 事業/サービスページ |
| 最近のニュース・お知らせ（日付つき） | トップ・ニュースページ |
| 採用状況（人手不足のサインになる） | 採用ページ |
| メール・電話・問い合わせフォーム・SNS | サイト全体 |
| 会社案内などの **PDF資料（ダウンロード）** | サイト内のPDFリンク |
| **AI商談準備メモ**（課題仮説・提案の切り口・ヒアリング質問・反論への切り返し） | Claude（APIキー設定時のみ） |

出力先は `output/日付_ドメイン/` です。

```
output/20261029_example.co.jp/
├── 商談準備シート.md   ← これを商談前に読む
├── pages.md           ← 各ページの本文（詳しく確認したいとき）
├── data.json          ← 取得データ（他ツール連携用）
└── pdf/               ← ダウンロードした会社案内など
```

## 初回セットアップ（1回だけ）

1. [Python](https://www.python.org/downloads/) をインストール（Windowsは「Add python.exe to PATH」にチェック）
2. このフォルダを VSCode で開く（「ファイル」→「フォルダーを開く」）
3. 右下に出る「推奨拡張機能をインストール」を押す（Python拡張）
4. `Ctrl+Shift+P` →「タスクの実行」→ **初回セットアップ（ライブラリのインストール）**
5. （AI分析を使う場合）`.env.example` をコピーして `.env` を作り、`ANTHROPIC_API_KEY=` にキーを貼る
6. `config/service.md` を丸投げコネクトのサービス説明に書き換える（AIの提案内容の精度が上がります）

## 毎回の使い方

1. VSCode で `Ctrl+Shift+B`（または `Ctrl+Shift+P` →「タスクの実行」→ **商談準備シートを作成**）
2. 商談相手のURLを入力して Enter
3. 完了したら `output/…/商談準備シート.md` を開き、`Ctrl+Shift+V` でプレビュー表示

ターミナルから直接実行することもできます。

```bash
python prep.py https://example.co.jp
```

| オプション | 内容 |
|---|---|
| `--max-pages 20` | 巡回するページ数を増やす（既定 12） |
| `--no-pdf` | PDFをダウンロードしない |
| `--no-ai` | AI分析をしない（APIキーがあっても使わない） |

## 注意点

- 相手サイトの `robots.txt` で禁止されているページは取得しません。アクセスは1秒間隔です。
- JavaScriptで中身を表示しているサイトでは、取得できる情報が少なくなることがあります。
- 会社概要の自動抽出は表（`<table>` / `<dl>`）形式に対応しています。取れなかった項目は「（未取得）」と表示されます。
- AI分析の内容は推測を含みます。商談前に必ずご自身で確認してください。
- `.env`（APIキー）と `output/`（顧客情報）は Git に含まれない設定になっています。
